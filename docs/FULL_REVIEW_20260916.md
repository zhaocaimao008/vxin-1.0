## 已修复

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| 切页、刷新后草稿消失 | ChatWindow 首次挂载未恢复草稿，只在会话 ID 变化时恢复。现在初始化即恢复，输入、表情和提及走同一持久化路径，编辑消息不覆盖未发送草稿。 | 浏览器中复现修复前两次均为空；修复后切页、刷新均恢复中文草稿。5 项草稿 E2E 通过。 |

| 深色设置页出现亮色背景，辅助文字偏暗 | 深色主题遗漏 `--bg-page`，部分辅助文字使用过暗颜色。补齐背景和辅助文字令牌。 | 5 种尺寸 × 2 种主题检查，深色设置页背景为 `rgb(21,23,26)`，切回浅色正确。 |

| 聊天搜索旧结果覆盖新结果，清空后旧请求仍回填 | 搜索只有防抖，没有取消或过期检查。现在取消旧计时器及请求，忽略已取消响应；搜索失败与无结果分别提示。 | 延迟旧查询、先完成新查询，再释放旧响应，结果仍保持最新；清空输入后结果消失。 |
| 阅后即焚保存失败仍显示已修改 | 请求前直接修改了选择值，没有恢复。现在成功后更新值，保存时禁用重复操作，失败保持服务端原设置。 | 注入 HTTP 400，原选择保留且出现失败提示。 |
| 服务器检测把 404、401 或普通 HTML 当成功 | 原逻辑把所有小于 500 的状态视为连接成功。现在要求成功响应且健康检查 JSON 为 `ok: true, db: ok`。 | 5 项单元测试覆盖错误状态、HTML、无关 JSON 和真实健康响应。 |
| 首屏无效预加载原始 JSX | 手写 modulepreload 被构建成额外的 `.jsx` 静态资产，约 5.7 KB，还会触发模块类型问题。移除后由 Vite 生成依赖预加载。 | 两种构建通过，最终浏览器资源记录中原始 JSX 请求数为 0。 |

创建群聊弹窗补充了 dialog 语义，方便辅助技术和自动检查准确定位。功能测试中也替换了原先恒真、允许不存在的导航等弱断言；文件代理使用真实 Cookie，不再注入 Alice 的令牌绕过权限。测试浏览器配置固定指向本地隔离服务。

## 性能数据与解释

最终构建的登录页，各使用全新浏览器上下文测 3 次；CPU 降速 4 倍，网络延迟 80 ms，下行 200,000 B/s、上行 100,000 B/s。下表为中位数，仅反映本机限速模拟，不能替代线上真实用户数据。

| gzip | 1.236 s | 2.796 s | 164,354 B | 0 |

仓库 Nginx 已配置 gzip，本轮没有新增线上压缩配置。压缩与未压缩的对比用于说明部署条件，不能当成本轮代码修改带来的整体提速比例。最后构建不再请求原始 JSX，搜索取消机制也避免无效请求继续占用客户端资源。

本地后端性能套件记录首次查询平均 7.60 ms、缓存命中平均 4.90 ms、单条查询平均 14.10 ms。该套件数据集小、运行在本机，且使用测试开关，未验证生产限流、长期负载、跨机 Redis 或大规模群聊。

仍有优化空间：首屏全局 CSS 未压缩约 251 KB；限速模拟中仍观察到长任务（最大 411 ms）。后续应在真实设备上结合生产压缩、远程配置延迟、长期消息量测量，再决定样式拆分和启动逻辑调整。本轮没有借测试数据声称所有性能问题已消除。

## 未解决风险及验证限制

1. **原生端账号隔离风险仍在。** 静态检查发现 Android/iOS 的独立 DraftStore、OutboxStore 仍主要按会话 ID 存储，重发入口没有与 Web 同等的发送者隔离防护。这些文件本轮未修改，也没有原生运行结果可以证明安全；需单独修复并做切账号/切服务器回归。
2. **Android 构建被环境阻挡。** 已实际执行 `:app:compileDebugKotlin`，Gradle 报缺少 Android SDK Platform 34、Build Tools 33.0.1 及对应许可；没有成功生成或运行 APK。iOS 所需 Xcode/Swift 工具链和 Apple 真机在本机不可用。
3. **桌面发布与 HTTP 自定义服务。** 未验证签名、自动升级、Windows/macOS、摄像头、系统通知。静态检查和本地日志还确认主进程 `fetchBuffer` 使用 HTTPS，导致自定义 HTTP 后端的功能开关请求失败并回退默认入口；HTTPS 生产配置不等于已受此问题影响，此处保留为桌面专项待办。
4. **真实业务链路未全部覆盖。** 通话只检查界面及信令，没有验证双端真实音视频、TURN/NAT；没有真实支付、短信、推送或外部云存储验收。此前分析中的部署回滚、原生缓存和加密设计问题不能据本轮 Web 测试宣称已解决。
5. **旧格式草稿不会自动迁移。** 旧键缺少可信的账号/服务器归属，为避免串号，新版不自动读取它；退出登录时清理旧格式键。升级前旧草稿可能不再显示。新格式草稿已验证恢复及隔离。
6. **仍未发布。** 本轮结果是本地源码与构建，线上用户需后续发布后才能得到修复。
