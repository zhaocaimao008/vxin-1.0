## 修复内容

1. **手机网页按钮被遮挡**：首次来电铃声提示条原来固定在页面最上方，覆盖“发起”和聊天返回按钮。将铃声提示、重连提示放进正常布局，并让聊天区域使用剩余高度。两个提示同时显示时也能点击入口。
2. **页面加载失败后不能恢复**：全局和聊天错误边界的“重试”原来只重挂载组件，`React.lazy` 会继续复用已失败的加载结果。改为刷新文档重新加载资源；“返回首页”遵循 `/app/` 部署路径及桌面 HashRouter。
3. **开启错误监控后启动白屏**：改用已安装 Sentry 10 的 integration 工厂函数，同时将跟踪目标配置放到当前 SDK 支持的位置。
4. **消息恢复与账号切换**：待发箱、历史缓存按服务器和账号隔离；重发前核对发送者和会话；退出、会话失效、切服时清理本地状态；切换账号同步更新 Bearer token。旧待发记录隔离保留，不自动作为当前账号的消息发送，退出登录时清理旧记录。
5. **空闲误断线、断线漏消息**：移除把“30 秒没有业务事件”当作断线的逻辑，使用 Engine.IO 心跳检测；重连补拉循环分页，后端新增 `afterId` 复合游标，避免超过 100 条或同一秒内多条消息被跳过。切换会话时取消未完成补拉。
6. **后端语法错误**：修正路径校验器中的反斜杠正则，消除语法检查和覆盖率收集失败。

新增可复用脚本，要求先启动隔离后端和含 `/api`、`/socket.io` 反向代理的 Web 服务。脚本会创建测试账号、群组和消息，使用测试数据库运行。

node e2e/scripts/navigation-smoke.cjs

API_ORIGIN=http://127.0.0.1:18386 \

根目录安装 Playwright 依赖并安装 Chromium 后运行。`SENTRY_DIST` 可省略，省略时不执行监控构建检查。`EVIDENCE_DIR` 可指定截图与 JSON 输出目录。页面扫描关闭 Service Worker 以便稳定注入资源故障；另行进行了启用 Service Worker 的真实缓存检查。
