# 再次全量复查（2026-09-16）

接续 [上一轮收尾报告](TODO_CLOSURE_20260916.md)。本轮重新检查用户入口、设置、媒体加载、失败分支、桌面实际运行、界面、性能和发布链路；使用隔离账号、数据库和端口，没有向真实联系人发送测试消息。

## 本轮发现并修复

1. **客户端下载仍拿到旧包**：登录页固定使用 Windows latest 别名，公网该文件与当前更新清单的文件大小不同。改为校验清单后使用带版本号的 Windows/Android 下载地址；清单失败时保留官网下载入口。Windows 发布同步更新旧别名，校验 SHA512 并保留回滚。
2. **服务器检测误报和桌面拦截**：登录页、登录后的设置页重复实现了宽松检测，404/HTML 也会显示成功。统一要求成功状态和 `{ok:true,db:"ok"}`；修复修改地址后旧结果覆盖新结果。桌面检测新来源经限定的主进程健康检查接口完成，保留 CSP，仅请求 `/health`，不携带会话、不跟随重定向、限制响应大小和超时。
3. **取消切换仍改变状态**：登录前和登录后的服务器切换均等待原生确认结果；取消时不退出登录、不清草稿、不写新服务器。确认后同步运行时地址和持久化配置，重新加载使 WebSocket 与安全策略跟随新服务器。显式自定义 HTTP 地址保留支持，原生确认框标明未加密连接。
4. **媒体路径与鉴权**：绝对路径的受保护桌面图片缺少令牌，旧查询令牌/片段会导致鉴权失败；Web 媒体还可能忽略配置中的 API 来源。统一解析路径，只有桌面/原生端当前后端的 `/uploads/` 资源获得当前令牌，不向外部来源发送会话令牌。修复前单测复现 4 项失败。
5. **登录限流可绕过**：限流键与登录服务的字段优先级、空格处理不一致，混入无关字段或改变空格即可分散失败次数。按真实登录方式和归一化账号计数；成功请求仍不累计失败额度。修复前新增回归复现 2 项失败。
6. **文档和帮助入口无响应**：登录/注册可打开既有隐私正文，帮助提供找回密码、注册、下载入口；小屏和桌面可读，关闭保留输入。实际 Electron 曾拦截 iframe，已改为净化后显示随包文档，没有放宽安全策略。仓库缺少用户协议正文，界面明确告知，未编造条款。公网补查发现深色主题将正文链接覆盖成白底金字，已修复选择器优先级，默认和悬停状态均有颜色断言（悬停修复前实际复现为金色，修复后通过）。
7. **桌面依赖遗漏**：补查整个桌面依赖树发现 npm 报告 13 个高危、1 个严重依赖项（其中运行依赖 2 个高危）。升级 Electron 至 44.4.1、electron-builder 至 26.15.3 和相关锁定依赖；适配构建配置、Node 22 与运行时下载方式。最终完整桌面审计为 0 已知漏洞，并加入 CI 门禁。
8. **快速连发停在失败态**：全套回归暴露服务端每秒 3 条限流下，连续 5 条的后两条未落库。保留限流并返回明确重试信息，客户端在窗口后使用同一幂等键有限重试；超时、切换账号/会话、断线时停止重试，永久错误不重试。修正原测试未等历史加载便统计所有气泡的问题，并增加服务端精确 5 条、无失败图标、刷新后仍各一条的断言。
9. **上滑被自动贴底覆盖**：重复回归复现历史刚加载时自动滚动的 500ms 窗口会覆盖用户向上滚动；滚轮、触摸上滑和向上滚动按键立即取消自动跟随，待执行动画帧也会检查取消状态。历史测试先写入真实已提交消息，避免批量发送与滚动混在一起。修复后连续 5 轮、10 项全部通过。
10. **测试与巡检**：收紧错误密码、刷新登录保持、重复提交等弱断言；生产巡检识别带 `^~` 的实际 uploads 路由。最终云端通话用例复用主叫账号，连续运行会受 5 秒呼叫冷却影响，曾有 3 项接听等待重试；已改为每例独立账号/会话，明确等待双方 Socket 连接，保留真实冷却策略和原有媒体断言。
