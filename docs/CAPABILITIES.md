# 当前能力与历史报告边界

以 `backend-v2`、`web`、`desktop-electron`、`android`、`ios` 的实际运行代码为准。
`docs/archive/` 的优化总结是历史设计/实验记录，其中“已完成”“全量覆盖”不作为发布验收结论。

- 消息由服务端处理并保存在 SQLite，服务端可以读取消息正文；当前没有消息端到端加密。
  HTTPS/WSS 保护传输；WebRTC 媒体使用浏览器的加密传输。这些不能替代消息 E2EE。
  `e2eEncryption.js` 是未接入聊天收发流程的实验工具，不是 Signal Protocol，不能据其单测宣称前向保密。
- 当前部署是单实例 Express + Socket.IO + SQLite，Redis 用于缓存等功能。没有完成多实例实时广播、跨区域数据库复制或自动故障转移验收。
  P7/P8 原恒真测试已改为 `test.todo`，不计入通过数。
- 钱包有内部账本、红包、转账和幂等测试；生产默认关闭假充值。当前没有可宣称完成的真实第三方收单支付链路。
- 推送、短信、对象存储、语音转写依赖运营环境凭据或外部服务。配置项存在、模拟测试通过、安装包生成均不等于真实设备送达或真实交易成功。
- 旧版本未带账号/服务器归属的草稿不能安全自动归入当前账号。新版不自动读取，退出时清理旧格式；新格式按账号与服务器隔离。无法从缺失的信息推断可靠归属。

最新检查与证据以 `TODO_CLOSURE_20260916.md` 为准；新增协议、支付网关或多区域基础设施属于独立功能开发，不能通过修改文案或空测试完成。
