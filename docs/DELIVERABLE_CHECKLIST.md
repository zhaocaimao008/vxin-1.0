## 三、功能清单

### 3.1 IM 核心
- 单聊 / 群聊,消息收发:文本、图片、语音、视频、文件
- 引用回复、消息删除、消息转发
- 已读回执、未读数、@我的
- 全局搜索、消息搜索、离线消息缓存
- 会话:置顶、免打扰、背景图、清空、删除

### 3.2 群组
- 建群、群邀请、群公告、群信息修改、群头像
- 成员管理:踢人、设管理员、转让群主、退群、解散
- 全员禁言

### 3.3 社交
- 好友:搜索(手机号/用户名)、添加、好友请求(接受/拒绝)、备注、标签、黑名单
- 朋友圈:发布(文字/图片)、点赞、评论、动态通知
- 收藏、个人二维码、专属邀请码

### 3.4 通话
- 真 WebRTC 语音/视频:1v1 + 群组通话
- STUN + TURN 中继(时效凭证接口)

### 3.5 钱包/红包
- 余额体系(事务化,防并发扣减)
- 红包:发送/领取/详情,余额校验
- 充值接口预留(见 §五 限制)

### 3.6 表情包
- 表情包管理、发送

### 3.7 推送
- **Android**:FCM 通道
- **iOS**:APNs(后端直连,ES256 Provider Token)
- **个推 GeTui**:接口已留,需凭据(见 §五)

### 3.8 管理
- 管理后台:用户管理、封禁、安全审计(admin 模块)

## 五、交付前须知(4 项限制,需与客户对齐)

1. **充值网关未接**:钱包充值接口为占位,红包走虚拟余额。生产上线需自行接入微信支付/支付宝。
2. **个推未配**:华为/小米/OPPO/vivo 等无 GMS 国产 ROM 的锁屏兜底推送需要个推应用凭据(APP_ID/APP_KEY/MASTER_SECRET),买家自行申请配置。有 GMS 设备不受影响(FCM 直通)。
3. **注册限流**:按 IP 限次,属安全设计,可按需调整。
4. **合规**:正式运营需 ICP 备案、等保评估;消息未做端到端加密,上架应用商店需补充隐私政策与实名/风控方案。
